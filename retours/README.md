# retours — vos conseils et remarques

Un endroit sans prise de tête pour laisser un **retour** sur un TP : ce qui vous a bloqué, une
consigne ambiguë, un outil que vous avez trouvé plus pratique, une idée, un encouragement…
**Tout est utile, même une seule ligne.** Le prof lit tout et intègre les bonnes idées (créditées).

## Comment ajouter un retour

Au choix, le plus simple pour vous :

- **Retour court** : modifiez [`retours.md`](retours.md) et ajoutez une puce en bas.
- **Retour plus long / plusieurs points** : créez un fichier `retours/votre-prenom.md`.

Dans les deux cas, GitHub vous proposera d'ouvrir une **pull request** (il crée automatiquement
votre copie du dépôt). Voir [`../CONTRIBUTING.md`](../CONTRIBUTING.md) si c'est votre première fois.

## Format suggéré (libre)

```
- [TP1] Mission 2 : j'ai perdu 10 min car je ne trouvais pas exiftool. Préciser le menu aiderait. — Prénom
```

Indiquez le **TP** et si possible la **mission** concernée. Merci !

> Astuce : pour une *correction* directe (coquille, bug), inutile de passer par ici — modifiez
> directement le fichier concerné et ouvrez la pull request.
